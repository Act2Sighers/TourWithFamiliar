# ファミリア・戦闘 仕様(確定分と暫定分)

ユーザーから説明を受けた内容の記録。**推測で足した部分は「暫定」と明記**する。迷ったらここを正とし、変更があればここを先に更新する。

## 1. 用語

### パラメータの4分類
| 分類 | 内容 | 例 |
|---|---|---|
| 能力値 | 個体差を生む固定パラメータ。自然数。増加は段階的で、アップグレードやレベルアップ時のみ | 丈夫さ / 攻撃力 / 素早さ |
| 実効数値 | ゲームシステムが直接使う可変パラメータ。能力値や状態値から算出され、状況で変動する | HP / 攻撃威力 / 移動速度 / 攻撃間隔 |
| 状態値 | 能力値を参照しない共通パラメータ。蓄積・減少の速さは実効数値側にあり個体差が出る。上限は関係値の影響を受ける | 疲弊 / 希望 |
| 関係値 | 他のパラメータの影響を受けない | 成長度 / 親密度 |

- 成長度は疲弊の上限を増やし、親密度は希望の上限を増やす。
- 疲弊・希望は将来、攻撃威力や移動速度にも影響する(未実装)。

### キャラクターの種別
- **観測者**: プレイヤーの分身。能力値を持たない。最大HPは固定(一部のレリックで補正)。移動のみ可能で、攻撃は一切できない。
- **ファミリア**: 観測者のお供。AI操作。
  - **側近**: 戦闘不能になっても画面に残り、観測者が助け起こす。観測者と共にいる側近が最低1人必要。人数に上限がある(全員を側近にはできない)。
  - **同行者**: 側近でないファミリア。戦闘不能で約1.5秒後に消え、拠点へ送還扱いになる。
- **中立個体**: マップ上で単独で動いているキャラクター。観測者がインタラクトしてファミリアにする過程を「雇用」と呼ぶ(ゲーム開始時に選ぶ最初の側近1人だけは例外)。
- **敵個体**: 観測者もファミリアも区別せず攻撃対象とする。

### 関係値の扱い
- 成長度: 中立個体にも存在するが、生成時に決まるだけで中立の間は変動しない。ファミリアになりある程度経過して初めて上昇。特定条件下で減少する。
- 親密度: 中立個体には存在しない。ファミリアになった時点で1。行動を共にした時間でごくゆっくり上昇。

## 2. HP
- ファミリアの最大HP = 「丈夫さ」に基づく値。下限は0。0で行動不能。
- 観測者のHPは固定の最大値(能力値なし)。観測者が倒れるとラン終了。
- **HPゲージ(全キャラ共通)**: 観測者・ファミリア・敵のすべてが横棒ゲージで表示。ただし**現在HP = 最大HP のときと、HP = 0 のときは表示しない**(全快か0かは他の要素で区別する)。

### 戦闘不能
- **側近**: その場で動けなくなり、画面に残る。観測者が近づいてインタラクトし続けると「助け起こし」が進む。
  - 完了まで最低3秒程度。進捗は**扇状のゲージ**で表示。
  - 完了すると最大HPの15%程度で復活。将来は、疲弊が大きく蓄積したり希望が大きく減少したりする可能性がある(未実装)。
- **同行者**: 約1.5秒後に画面から消え、自動的に拠点へ送還扱い。拠点ではHPが全快していなければ時間でゆっくり回復(速度は要調整)。最大HPの50%以上に回復するまで、観測者からの召喚指示を拒否する。
- 拠点・送還・召喚の実装は直近の段階とは切り離す。
- **存在範囲の外で戦闘不能になったファミリア**は、側近であっても同行者と同じく強制送還する。ただし、そのファミリアが側近の最後の1人である場合だけは送還せず、側近として通常の戦闘不能処理を行う。

### 戦闘不能の実装方針(M1c。※印は暫定)
- 側近の助け起こし: 観測者が、戦闘不能の側近から一定の距離(※中心間48)以内で、インタラクトボタンを**押し続ける**と進む。所要3秒。進捗は扇状のゲージで表示。完了で最大HPの15%で復活する。
  - ※途中で離す/離れると、進捗は最初からになる(保持するかは調整パラメータ)。
  - ※距離内に複数いる場合は最も近いファミリアが対象。
- 同行者(と、強制送還が決まった側近): 戦闘不能から1.5秒かけて薄くなって消え、拠点へ送られた扱いになる。M1cでは「拠点」は単なる保管先で、回復も召喚もまだ無い。
- ※側近の最後の1人かどうかは、フィールド上にいる(戦闘不能を含む)他の側近がいるかで判断する。
- ※戦闘不能の間は押し合いに参加せず、敵にも狙われない。

### 観測者が倒れたとき
- 「倒れた」と表示する。そこから**2秒間はウェイト**を挟み、その間プレイヤーは何もできない(移動もメニューも不可)。ウェイト中もワールドは動き続け、ウェイトが終わるとワールドが止まる。
- ラン終了の画面はまだ作らない(M1cの範囲外)。

## 3. 攻撃
- 攻撃威力 = (武器の「攻撃性」を参照したダメージ基礎値) × (ファミリアの「攻撃力」を参照したダメージ係数)。
- ダメージはそのままHPを減らす(防御による軽減なし)。
- 武器はファミリアが最初から持つか、観測者が持たせる/持ち換えさせる。**何も持たない場合は内部的に「素手」を持っている扱い**。素手は弱いが、ダメージが出せない状態を避けるために存在する。
- **近接攻撃 = 範囲攻撃**: 武器ごとに定められた範囲に、一瞬だけヒット判定を出す。接触した相手に、1回のヒット判定につき1体につき1回だけダメージを与える。
- **素手の特性**: キャラクターの前方の小さい攻撃範囲 / 中程度の前隙・後隙 / 短い持続 / 遅い攻撃間隔。
- 攻撃範囲・隙・持続は武器ごとに固定。**攻撃間隔は実効数値**で、それを決める能力値は後で用意する。(M1bでは武器固有の値をそのまま使う)

### 攻撃処理の実装方針(※暫定)
- 流れ: 前隙 → 持続(ヒット判定が出ている間) → 後隙 → 待機。攻撃間隔は「攻撃を始めてから次の攻撃を始められるまで」の時間。
- 前隙・持続・後隙の間は行動できない(動けない)。向きは攻撃開始時に固定。
- ヒット判定は、前方に置いた円。接触した相手に、1回の攻撃につき1体1回だけダメージ。
- 攻撃を始める距離は、相手が範囲内に入りそうな距離。前隙中に相手が動けば外れることもある。
- キャラクター同士の体の衝突(押し合い)は、まだ無い。
- 敵もファミリアと同じ仕組み(能力値・武器)で攻撃する。敵は何も持たないので素手。

## 4. 移動
- 移動速度は実効数値で、「素早さ」に基づく。素早さに差があれば速度にも差が出る。
- 初期のファミリアの移動速度は、観測者と同じか、ほんの少し遅い程度。
- **旋回は即時**(向きの変更は一瞬)。**移動には慣性がある**。
- **「移動速度」に当たるものは、その瞬間の速さではなく「到達し得る最高速度」を指す**(迷子速度など、他の値が移動速度を参照するときも同様)。

## 4.5 押し合い(衝突)
- 観測者・ファミリア・中立個体・敵など、**すべての存在が自身の大きさを参照して押し合う**。
- 大きい存在ほど、押し合いで動かされにくい。※質量 = 半径の2乗(べき乗は調整可能)。
- ※戦闘不能(HP0)のキャラクターは押し合いに参加しない(助け起こしのために近づけるようにするため)。

## 4.6 見た目(プレースホルダー)
- **名前**: すべての存在が、本体の中心に名前を白い文字で表示する。名前は、収まる円(描画しない)に収まる大きさにする。円の本体は、半径の80%の円。**正多角形の本体は、その内接円に収める**(今後、他の正多角形の存在を実装する場合も同じ。円だけが例外で、半径の80%)。文字の大きさは一定でなく、その円に収まることを優先する。本体からはみ出してもよい。
  - 名前: 観測者は「◎」(文字ではなく図形)、ファミリアは「FM」、敵は「EN」、中立個体は「NU」(※暫定)。種類が増えたらその都度名前を用意する(基本はアルファベット2文字のイニシャル)。
- 観測者・ファミリア・中立個体: 円。向きを示す白い二等辺三角形(底辺:高さ = 2:1、頂点が直角)を持つ。直角の頂点が向いている方向に来て、**本体の円の外周に接する**。大きさは、底辺が半径の0.6倍(高さが0.3倍)。
- 敵: 正三角形(外接円が半径)。向いている方向に角の1つが来る。徘徊は淡い色、臨戦は濃い色。名前は、正三角形の内接円(半径の半分)に収める。
- 色(※暫定): ファミリアはピンク(同行者はオレンジ)、中立個体は緑、観測者は紫。
- 臨戦(迎撃)中のファミリアと中立個体には輪郭を付ける。戦闘不能は灰色。

## 5. AI(ファミリア・敵。ユーザー指示。※印は私の叩き台で「暫定」)

### 状態
| ファミリア | 敵 |
|---|---|
| 待機(デフォルト) | 徘徊(デフォルト) |
| 迎撃 | 臨戦 |

- 敵が「臨戦」になる条件: いずれかのファミリアまたは観測者を攻撃対象と認識したとき。

### 距離・範囲の用語(すべて観測者や自身を中心とした円)
| 用語 | 定義 | 備考 |
|---|---|---|
| 待機範囲 | 観測者から一定距離内(初期値: 半径120) | |
| 応戦範囲 | 待機範囲の3倍 | |
| 存在範囲 | 待機範囲の15倍 | 15倍は暫定。後で変えるかもしれない |
| 索敵範囲 | 待機範囲の2倍。敵が自身を中心に攻撃対象を探す範囲 | 見失う条件(応戦範囲)とは別にする |

### 待機(ファミリア)
- 最低限の条件: 観測者から待機範囲内に留まる。
- 観測者が立ち止まっていても、待機範囲内で気まぐれに立ち止まったり動き回ったりする。
- 観測者の歩き続ける速さにファミリアが追いつけなくなる(取り残される)ことは**意図的に残す**。ファミリアが観測者に都合の良い存在になりすぎないため、また観測者とファミリアは絶対的な主従ではなく、ある程度対等な関係であるという世界観のため。システム側の都合でプレイヤーに楽をさせない。

### 徘徊(敵)
- 仮実装: ファミリアの待機時の挙動から、範囲指定を取り除いたもの(立ち止まる/歩くを繰り返す)。

### 敵の攻撃対象の認識
- 徘徊中、索敵範囲(待機範囲の2倍)内にいる攻撃対象を認識すると「臨戦」になる。複数いる場合は※最も近い相手を狙う。
- 臨戦中、攻撃対象が自身を中心とした応戦範囲の外に出たら見失い(諦め)、徘徊に戻る。攻撃対象が戦闘不能などになった場合も同様。
- 敵は観測者とファミリアを区別しない。
- 将来: 「性格」(実効数値の1つだが値ではない)を導入し、執拗に追いかける/逃げ出す、などの違いを加える(未実装)。

### 迎撃(ファミリア)
- 敵が「臨戦」になったら、ファミリアは「待機」から「迎撃」になり、待機範囲の制約を一時的に無視して戦闘に向かう。複数の敵が臨戦なら※最も近い敵を選ぶ。
- 迎撃は、それを発生させた敵**1体**を認識し、解除されるまでその敵を狙い続ける。他の敵が観測者を襲っても反応しない(現状の仮実装)。
- **迎撃の解除条件**(どちらか):
  1. その敵が戦闘不能になった
  2. その敵が臨戦でなくなった(少なくとも、ファミリアや観測者を攻撃対象から外した)**かつ**、応戦範囲の外へ出た
- ※2の応戦範囲は、観測者を中心とした円として扱う(待機範囲が観測者中心のため)。

### 存在範囲(取り残されたファミリアの扱い)
- ファミリアが存在範囲の外にいる間:
  - 敵はそのファミリアを攻撃対象として認識しない。
  - そのファミリア自身が「迎撃」になることもない。
  - 戦闘不能でなければ、観測者に追いつこうとして移動する。移動速度は**迷子速度**になる。存在範囲内では、素早さや疲弊から算出される本来の移動速度。
  - **迷子速度 = その時点で観測者が到達し得る移動速度の最高速度の1.5倍**。観測者が止まっているかどうかには左右されない。
- 存在範囲の外で戦闘不能になったファミリアは、側近であっても同行者と同じく強制的に送還する。ただし、そのファミリアが側近の最後の1人である場合だけは送還せず、通常の側近の戦闘不能処理を行う。(M1cで実装)

## 6. 操作の原則
- ラン中にゲームシステムがプレイヤーへ要求する操作は、**移動以外は常に1つのボタンに集約する**。
- そのボタンの機能は状況で決まり、優先順位がある(例: 助け起こしが必要な戦闘不能のファミリアが十分近くにいるなら、他のファミリアが近くにいてもコミュニケーションはできない)。
- 割り当て(暫定): キーボードは E、ゲームパッドは A ボタン、タッチは画面上のボタン。対象が近くにいる間だけ、画面上のボタンを表示する。
- ボタンの機能は、対象の優先順位で決める。M1cでは「戦闘不能の側近の助け起こし」だけ。

## 8. 中立個体と雇用(M2)
ユーザー指示。※印は私の叩き台(暫定)。

### 中立個体(M2aで実装済み)
- ワールド上に単独でいる存在。敵よりも少ない割合でスポーンする(仮実装は固定スポーン)。
- ファミリアになるまでの挙動は、仮実装として敵の徘徊と同じ(範囲の制約が無い、立ち止まる/歩くの繰り返し)。
- 能力値は、ファミリアと同じ初期値(※調整パネルでは別に設定できる)。素手で戦う。
- 他のすべての存在と同じく、押し合いに参加する(戦闘不能の間を除く)。
- **戦闘不能になった中立個体**: ファミリアと同じく灰色になり、その場に残り続ける。敵に狙われない。雇用はできない(蘇生能力を持つファミリアなどが登場するまで、この仕様は変わらない)。ただし、観測者を中心とした**存在範囲の外に出たら消える**。
  - 存在範囲の外にいる、生きている中立個体は、消さない(確認済み)。
- **スポーン上限**: ワールド全体で10体(確認済み。問題が出たら見直す)。ゲームとしてのスポーン(初期配置・デバッグ・将来のスポーナー)は、必ずこの上限を守る。雇用されて減れば、また出せる。

### 中立個体と敵の反応(M2aで実装済み)
- **反応範囲** = 待機範囲と同じ大きさの範囲。
- 敵は、自身を中心とした反応範囲に中立個体がいれば、その中立個体に対して臨戦になる。応戦範囲(敵が中心)の外へ出られると見失う。
- 中立個体は、いずれかの敵が自身に対して臨戦になると臨戦になり、その敵と戦う(追いかけて素手で攻撃する)。応戦範囲(中立個体が中心)の外へ敵が出ると見失う。「逃げる」行動はまだ無い。
- 観測者・ファミリアは、これまでどおり索敵範囲(待機範囲の2倍)で認識する。敵は、認識できる相手のうち**最も近い相手**を狙う。
- ファミリアの迎撃は、「ファミリアまたは観測者を攻撃対象にした敵」だけが対象。中立個体を狙う敵には反応しない。

### 雇用(M2bで実装済み)
- 操作はインタラクトボタン。助け起こしと違い、待ち時間は無い(押した瞬間に確認ダイアログが出る)。
- 確認ダイアログ「〇〇を雇用しますか？」。〇〇は、種類の違いが無い今は「この中立個体」。ダイアログが出ている間は**ワールドが止まる**。
  - 了承 → その中立個体はファミリア(**同行者**)になる。キャンセル → 中立個体のまま。
- インタラクトの優先順位: **助け起こし > 雇用**。ボタンが出る距離は、雇用のほうを大きくする(戦闘不能でない中立個体とは押し合いが発生し、近づけないため)。※雇用の距離は中心間72。
- 人数上限(暫定の固定値): **側近2人、ファミリア5人**(同行中の人数。拠点にいる者は含めない)。将来は、一部のレリックや、同行中の全ファミリアの親密度の平均で増える。
  - 上限で雇えないときは、「これ以上同行できません」というダイアログ(OKのみ)を出す。
- 現状、同行者を側近にする方法は存在しない。
- ※ダイアログの操作: キーボードは Enter(はい)/ Esc(いいえ)、ゲームパッドは A(はい)/ B(いいえ)、タッチは画面のボタン。
- 雇用は「押した瞬間」に反応する操作(押し続ける助け起こしとは違う)。押しっぱなしでも繰り返し出ない。
- 雇用された個体は、**同じIDのまま**ファミリアになり、位置・HP・能力値を引き継ぐ。その個体を狙っていた敵は狙い続け、その時点から「観測者側への臨戦」として扱われる(ファミリアが迎撃する)。
- 人数は、同行中のファミリアで数える(戦闘不能で残っている者や、送還が決まって消えるまでの者も含む。拠点の者は含めない)。

### 最初の側近の選択(M2cで実装済み)
- ラン開始時に、プレイヤーが最初の側近を1人選び、「開始」を押すとランが始まる。
- ファミリアに種類が無い今は、候補は1種類だけ(仮実装)。
- 選択画面: 候補を並べたカード(名前と能力値: 丈夫さ・攻撃力・素早さ)と、「開始」ボタン。候補を選ぶまでは「開始」を押せない。選択画面の間はワールドが止まっていて、メニューも開かない。
- 操作: ← → / 十字キーで候補を選ぶ(動いた先が選ばれる)。Enter / A は、未選択なら焦点の候補を選び、選択済みなら開始する。画面では、カードのタップと「開始」ボタン。
- 調整パネルの「シード再生成」は、選択画面へ戻る動きにする(確認済み)。
- ファミリアの種類は `FamiliarKind`(名前と初期の能力値)として一覧にしてあり、種類が増えたらここに足す。選択画面の候補もこの一覧から作る。
